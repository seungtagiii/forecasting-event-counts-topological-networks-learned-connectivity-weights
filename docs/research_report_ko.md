# 위상 정보를 활용한 결정론적 연결 모형의 통신망 경보 발생 개수 예측: 다섯 모형의 실증 비교

> 연구 이해와 교수 미팅 준비를 위한 상세 보고서 · 작성일: 2026년 10월 5일
> 이 문서는 현재 완료된 실제 데이터 실험을 논문 형식으로 정리한 초안이다. 새로운 모형의 발명이나 일반적인 우월성 증명보다는, 특정 통신망 경보 데이터에서의 예측 성능 비교에 초점을 둔다. 시뮬레이션 결과는 본 보고서의 분석 범위에 포함하지 않았다.

## 초록: 한글

위상 정보를 갖는 네트워크의 사건 발생량 예측은 장비 간 물리적 연결과 사건 유형 간 의존성을 함께 고려해야 한다. 최근 TNPAR와 S²GCSL은 이러한 정보를 활용한 구조 학습을 발전시켰으나, 구조 복원 중심의 설계가 발생 개수 예측에도 효과적인지는 별도의 검토가 필요하다. 본 연구는 예측 목적에 학습 가능한 연속 연결 가중치가 더 적합할 수 있다는 관점에서, TNPAR, 직접 변분 모형, 연속 연결 가중치 모형, S²GCSL, THP의 성능을 비교하였다. 공개 통신망 자료인 24V_439N_Microwave의 439개 장비와 24개 경보 유형을 대상으로 발생 이력을 60초 단위로 집계하고, 시간순 학습·검증·테스트 분할을 적용하였다. 연속 연결 가중치 모형은 학습한 연결 가중치를 과거 입력에 직접 적용하여 포아송 기대 발생량을 산출한다. 동일 자료에서 세 번 학습한 결과, 이 모형의 평균 예측 음의 로그우도는 0.001517로 다섯 모형 중 가장 낮았으며, TNPAR 대비 17.3%, 직접 변분 모형 대비 16.9% 감소하였다. 다섯 모형 중 MAE와 RMSE도 가장 낮았고, 세 학습 반복에서 예측 성능 순위가 유지되었다. 제공된 참고 연결 라벨에 대한 AP는 0.300으로 TNPAR(0.278), 직접 변분 모형(0.293), THP(0.244)보다 높았으나 S²GCSL(0.335)보다 낮았다. 이러한 결과는 연속 연결 가중치의 예측상 이점을 보여주며, 향후 다양한 네트워크 자료와 시간에 따라 변화하는 연결 구조로 연구를 확장할 근거를 제공한다.

**주요어:** 사건 발생 개수 예측, 위상 정보, 학습 가능한 연결 가중치, 포아송 모형, 네트워크 사건 시계열

## Abstract: English

Forecasting event counts in networks with known topology requires accounting for both physical connectivity and dependencies among event types. Recent models, including TNPAR and S²GCSL, have advanced structural learning in this setting, but their emphasis on structural recovery leaves open whether their connectivity representations are well suited to count forecasting. We investigate whether learned continuous connectivity weights offer a more effective representation for prediction through an empirical comparison of TNPAR, a direct variational model, a continuous connectivity weight model, S²GCSL, and THP. Experiments use the public 24V_439N_Microwave dataset, containing 439 devices and 24 alarm types. Event occurrences are aggregated into 60-second intervals and divided chronologically into training, validation, and test sets. The continuous connectivity weight model directly applies learned weights to historical inputs to produce Poisson predictive means. Across three training repetitions on the same dataset, it achieves the lowest mean predictive negative log-likelihood among the five models, at 0.001517, representing reductions of 17.3% relative to TNPAR and 16.9% relative to the direct variational model. It also achieves the lowest MAE and RMSE among the five models, with its leading prediction rank maintained across all three repetitions. Its average precision against the provided reference connectivity labels is 0.300, exceeding TNPAR (0.278), the direct variational model (0.293), and THP (0.244), but remaining below S²GCSL (0.335). These findings demonstrate predictive benefits of learned continuous connectivity weights in this setting and motivate extensions to additional network datasets and connectivity structures that vary over time.

**Keywords:** event count forecasting; topology-aware modeling; learned connectivity weights; Poisson models; network event sequences

## 1. 서론

### 1.1 연구 배경

통신망에서는 장비의 장애나 상태 변화가 경보 형태로 기록된다. 특정 장비에서 발생한 경보는 그 장비의 이후 경보뿐 아니라 인접 장비의 경보와도 관련될 수 있다. 예를 들어 한 장비의 장애가 연결된 장비의 서비스 이상으로 이어진다면, 인접 장비의 과거 경보는 이후 발생량을 예측하는 데 도움이 될 수 있다.

이러한 자료를 분석할 때는 두 종류의 연결을 구분해야 한다. 첫째는 장비와 장비 사이의 **물리적 연결**이다. 이는 통신망 자체의 구조이며, 본 연구에서는 알려진 입력 정보로 사용한다. 둘째는 경보 유형과 경보 유형 사이의 **예측적 의존 관계**이다. 이는 어떤 유형의 과거 경보가 다른 유형의 이후 경보를 예측하는 데 기여하는지를 나타내며, 모형이 학습하는 대상이다.

TNPAR는 위상 정보를 활용하는 신경 포아송 모형과 잠재 그래프 추론을 결합하여 사건 시계열의 그레인저 인과 구조를 학습한다[1]. 그러나 예측을 위해 반드시 인코더와 확률적 그래프 추론이 필요한지는 별도의 경험적 문제이다. 동일한 발생 이력을 사용하더라도, 연결 확률을 직접 최적화하거나 연속 연결 가중치를 결정론적으로 학습하는 방식이 더 좋은 예측 성능을 보일 가능성이 있다.

### 1.2 연구 목적과 범위

본 연구의 목적은 공개 통신망 경보 데이터에서 연결 구조를 처리하는 다섯 가지 접근의 예측 성능을 비교하고, 결정론적 연결 모형의 활용 가능성을 검토하는 것이다. 핵심 연구 질문은 다음과 같다.

1. 결정론적 연결 모형은 인코더 기반 모형 및 직접 변분 모형보다 다음 구간의 경보 발생 개수를 잘 예측하는가?
2. 그 결과는 같은 데이터에서 학습을 다시 수행하여도 유지되는가?
3. 예측 성능의 개선을 연결 구조의 정확한 복원으로 해석할 수 있는가?

본 연구는 새로운 딥러닝 구조의 최초 제안을 주장하지 않는다. 기존 연구를 참고하여 구현한 모형들을 공통 관측 정보 아래 비교하는 **실제 데이터 적용·실증 비교 연구**로 위치시킨다. 또한 실제 데이터의 참 발생 강도와 참 그레인저 인과 구조는 관측되지 않으므로, 주된 결론은 관측된 발생 개수의 예측 성능에 한정한다.

## 2. 관련 연구와 기본 개념

### 2.1 TNPAR

TNPAR는 Topological Neural Poisson Auto-Regressive Model의 약자로, 과거 사건 발생 정보와 물리적 위상을 이용하여 이후 사건을 설명하는 신경 포아송 자기회귀 모형이다[1]. 인코더는 잠재적인 연결 구조의 분포를 추론하고, 디코더는 해당 연결과 과거 관측을 이용하여 발생량을 설명한다. 원논문의 주요 목적은 그레인저 인과 구조 발견이다.

본 연구에서 사용하는 TNPAR 모형은 원논문을 참고한 재구현이다. 원저자 코드와 실험 설정을 그대로 실행한 동일 재현이 아니며, 특히 인코더의 출력 구성과 예측 시 그래프 집계 절차에 구현상의 차이가 있다. 따라서 결과 표에서는 일관되게 **TNPAR 참고 인코더 모형**이라고 표기한다.

### 2.2 S²GCSL

S²GCSL은 위상 사건 시계열에서 그레인저 인과 구조를 학습하는 접근이다. 선형적인 사건 영향 표현과 구조 규제를 통해 비교적 단순하고 확장 가능한 구조 학습을 추구한다[2]. 사건의 발생과 지속에 관한 정보를 활용하는 원형과 달리, 본 연구의 공통 비교에서는 발생 이력만 사용하고 과거 5개 구간의 고정된 영향 창을 가정하였다.

따라서 본 연구의 S²GCSL 비교 모형은 **S²GCSL 참고 고정창 모형**이다. 원논문의 지속시간 기반 연속시간 모형을 동일하게 재현했다고 주장하지 않는다.

### 2.3 THP

THP는 Topological Hawkes Process를 뜻한다. 이 보고서에서 THP는 Transformer Hawkes Process를 의미하지 않는다. Hawkes 과정은 과거 사건이 이후 사건의 발생 강도를 증가시키는 효과를 표현하며, THP는 물리적 위상 정보까지 이용하여 그 영향을 모델링한다[3].

본 연구에서는 공개 gCastle TTPM 구현을 참고하여 고정된 부모 집합에 대한 EM 추정과 BIC 기반 그래프 탐색을 구현하였다[5]. 다만 원시 사건 시각에 대한 원형 우도를 그대로 사용하는 대신, 공통 예측 대상인 구간별 발생 개수에 맞춘 포아송 근사를 사용한다. 이하에서는 **THP 참고 모형**으로 표기한다.

### 2.4 그레인저 인과와 예측 성능의 구분

그레인저 인과는 다른 조건을 고려한 상태에서 변수의 과거 정보가 다른 변수의 미래 예측에 추가로 도움이 되는지를 다루는 개념이다. 이는 개입 실험으로 확인한 물리적 인과와 같지 않다.

특히 신경망 내부의 연결 가중치는 그 자체만으로 그레인저 인과의 증거가 되지 않는다. 여러 연결과 디코더 가중치가 서로 보완할 수 있고, 같은 예측을 만들어내는 서로 다른 구조가 존재할 수도 있기 때문이다. **예측을 잘하는 것과 연결을 정확히 찾는 것은 서로 다른 평가 문제**이다.

## 3. 데이터와 예측 문제

### 3.1 데이터 출처와 전처리

gCastle 공개 자료 저장소의 24V_439N_Microwave 데이터를 사용하였다[4]. 이 자료는 통신망 경보 기록, 장비 위상, 경보 유형 간 참고 연결 자료를 포함한다. 데이터 버전은 커밋 `1858e9c39d90a524e7d8ff8b9456f4b1f231ff03`으로 고정하였다.

| 항목 | 구성 |
|---|---:|
| 장비 수 | 439 |
| 경보 유형 수 | 24 |
| 원본 사건 기록 수 | 64,598 |
| 집계 구간 길이 | 60초 |
| 완전한 집계 구간 수 | 8,639 |
| 완전한 구간에 포함된 사건 기록 수 | 64,577 |
| 마지막 불완전 구간에서 제외된 기록 | 21 |
| 관측 기간 | 약 6일 |

구간은 시작 시각을 포함하고 종료 시각을 포함하지 않는 방식으로 집계하였다. 중복 기록을 임의로 제거하거나 경보가 적은 장비를 제외하지 않았다. 양의 지속시간을 갖는 기록은 약 0.28%에 불과하므로, 다섯 모형의 공통 입력에서는 종료 시각과 지속시간을 사용하지 않았다.

이 자료는 TNPAR와 S²GCSL 각 원논문의 실제 데이터 실험을 그대로 복제한 자료 구성이 아니다. 본 연구는 이 공개 자료에 대한 별도의 적용 실험이다. 제공된 `DAG.npy`도 실제 세계의 참 그레인저 인과가 실험적으로 확정되었다는 의미가 아니라, 연결 분석을 위한 **제공 참고 라벨**로 취급하였다. 해당 라벨은 예측 모형의 학습 입력으로 제공하지 않았다.

### 3.2 관측값과 예측 대상

장비를 \(n\), 경보 유형을 \(i\), 시간 구간을 \(t\)로 표시하면 관측값은 다음과 같다.

\[
Y_{n,i,t}=\text{장비 }n\text{에서 구간 }t\text{에 발생한 유형 }i\text{의 경보 개수}.
\]

관측값은 0 이상의 정수이며, 본 연구에서는 음수 관측값을 다루지 않는다. 예측 대상은 과거에 관측된 경보 이력이 주어졌을 때의 다음 구간 발생 개수와 그 예측 분포이다.

\[
Y_{n,i,t}\mid\mathcal H_{t-1}\sim\operatorname{Poisson}(m_{n,i,t})
\]

여기서 \(\mathcal H_{t-1}\)은 예측 시점 이전의 관측 이력이고, \(m_{n,i,t}\)는 해당 60초 구간의 조건부 기대 발생 개수이다. 이 포아송 분포는 실제 자료 생성 과정이 반드시 포아송이라는 단정이 아니라, 비교 모형들이 사용하는 예측 분포 가정이다.

예측값 \(m\)은 기대값이므로 0.2처럼 정수가 아니어도 된다. 반면 관측된 발생 개수 \(Y\)는 정수이다. 또한 \(m/60\)을 초당 평균 발생률로 환산할 수는 있지만, 실제 순간 발생 강도의 참값을 관측한 것은 아니다. **이 연구의 결과를 참 \(\lambda\) 예측 오차가 검증되었다고 표현하지 않는다.**

### 3.3 시간순 분할과 예측 방식

전체 시간 구간을 약 60%·20%·20% 비율로 학습·검증·테스트에 배분하였다. 처음 5개 구간은 과거 입력을 구성하는 데 사용하고 예측 대상에서 제외하였다.

| 구간 | 시간 인덱스: 시작 포함·끝 제외 | 예측 대상 구간 수 | 역할 |
|---|---|---:|---|
| 학습 | [5, 5183) | 5,178 | 모형의 파라미터 추정 |
| 검증 | [5183, 6911) | 1,728 | 학습률·규제 후보 및 학습 시점 선택 |
| 테스트 | [6911, 8639) | 1,728 | 선택된 모형의 최종 성능 평가 |

테스트에서 각 시점은 그 이전까지 실제로 관측한 발생 이력을 사용하여 한 구간 앞을 예측한다. 따라서 여러 날의 미래를 재귀적으로 한꺼번에 예측하는 실험이 아니라, 관측 이력이 순차적으로 갱신되는 **한 단계 앞 예측**이다. 테스트 구간의 이전 관측값을 이후 시점의 과거 입력으로 사용하는 것은 이 예측 설정의 일부이다.

### 3.4 매우 희소한 자료의 특성

테스트 평가 대상은 1,728개 구간 × 439개 장비 × 24개 유형으로, 총 18,206,208개의 관측값이다. 그중 양수인 관측값은 8,731개이며, 경보 발생 개수의 합은 10,434이다. 따라서 테스트 관측값의 약 **99.952%가 0**이다.

학습 구간 전체에서 한 번도 관측되지 않은 장비·유형 조합도 10,536개 중 8,912개, 약 84.59%이다. 이처럼 장비와 유형을 세분하면 매우 희소한 예측 문제가 된다. 전체 평균 지표가 작게 보이는 중요한 이유이며, 항상 0을 예측하는 기준선과 발생 구간에 대한 보조 분석이 필요한 이유이기도 하다.

## 4. 비교 모형과 아키텍처

### 4.1 물리적 위상을 이용한 과거 입력 구성

물리적 위상에서 장비 \(n\) 자신, 정확히 1단계 떨어진 장비, 정확히 2단계 떨어진 장비의 경보를 각각 집계한다. 이를 홉 \(k=0,1,2\)로 표시한다.

\[
X_{n,k,j,t,\ell}=\sum_{r}B^{(k)}_{nr}Y_{r,j,t-\ell},\qquad \ell=1,\ldots,5.
\]

\(B^{(k)}_{nr}\)는 장비 \(r\)이 장비 \(n\)에서 정확히 \(k\)홉 떨어져 있으면 1인 지시값이다. \(k=0\)은 자기 장비를 의미한다. 이 집계는 이웃 장비 수로 나누는 평균이 아니라 **발생 개수의 합**이다. 같은 홉에 있는 여러 장비는 경보 유형과 과거 시점이 같다면 하나의 합으로 묶이므로, 입력에서는 그 경보가 어느 이웃 장비에서 발생했는지 구분할 수 없다. 다만 예측 대상 장비 자체는 장비별 기본 발생 수준을 통해 구분된다. 신경망 모형은 집계 이후 \(\log(1+X)\) 변환을 적용한다.

예를 들어 유형 A의 경보가 자기 장비에서 한 번, 바로 이웃한 장비들에서 세 번 발생했다면, 자기 장비와 1홉 장비의 정보가 서로 다른 입력 묶음으로 전달된다. 신경망 모형의 입력 차원은 3개 홉 × 24개 유형 × 5개 지연으로 360이다.

### 4.2 결정론적 연결 모형

결정론적 모형은 각 홉·원인 유형·대상 유형에 대해 하나의 연속 연결 가중치를 학습한다.

\[
G_{k,j,i}=\operatorname{sigmoid}(\eta_{k,j,i}),\qquad 0<G_{k,j,i}<1.
\]

\(G\)가 작으면 해당 과거 입력을 약하게 전달하고, 크면 더 강하게 전달한다. 이 값은 모든 장비와 시간에 공유하지만, 홉과 유형 쌍에 따라 달라진다. 입력에 연결 가중치를 곱한 뒤 대상 경보 유형별 신경망으로 전달한다.

\[
m_{n,i,t}=\operatorname{softplus}\!\left[
b_{n,i}+f_{\theta_i}\!\left(\operatorname{vec}\{G_{k,j,i}\log(1+X_{n,k,j,t,\ell})\}\right)
\right]+10^{-8}.
\]

\(b_{n,i}\)는 장비·유형별 기본 발생 수준이고, \(f_{\theta_i}\)는 대상 유형별 MLP이다. MLP는 폭 32의 은닉층 두 개와 Tanh 활성함수를 사용한다. Softplus는 출력 기대값이 양수가 되도록 하는 변환이다.

```text
장비별·유형별 과거 경보 + 알려진 물리적 위상
                       ↓
자기 장비·1홉·2홉의 최근 5구간 발생 개수 집계
                       ↓
log(1+발생 개수) × 학습 가능한 연속 연결 가중치 G
                       ↓
대상 경보 유형별 MLP + 장비·유형별 기본 발생 수준
                       ↓
Softplus로 양수 기대 발생 개수 m 산출
                       ↓
다음 60초 구간의 포아송 예측 분포 및 기대 발생 개수
```

여기서 ‘결정론적’은 연결 가중치를 예측 때 무작위로 뽑지 않는다는 뜻이다. 미래 경보가 확정되어 있다는 뜻은 아니다. 예측 결과는 여전히 포아송 확률분포이다. 또한 예측에 사용하는 \(G\)는 연속값이며, 0 또는 1의 딱딱한 연결 마스크가 아니다. 연결 평가를 위한 임계값 판정은 예측 계산과 별도의 분석이다.

### 4.3 TNPAR 참고 인코더 모형

인코더는 입력을 잠재 연결 분포로 바꾸는 신경망이고, 디코더는 그 연결과 과거 정보를 이용하여 발생량을 계산하는 신경망이다. 본 구현의 인코더는 과거 입력 360개와 학습 중 현재 대상 유형의 발생 개수 1개를 함께 받아, 대상 유형으로 들어오는 3개 홉 × 24개 유형의 연결 확률을 출력한다. 유형별 인코더는 폭 32의 은닉층 두 개를 사용한다.

학습에서는 현재 관측값을 설명하기 위한 잠재 연결을 추론하므로 현재 대상 관측값을 인코더에 넣는다. 그러나 미래 예측 시에는 현재 대상 관측값을 알 수 없다. 이에 따라 본 구현에서는 최대 50,000개의 학습 구간 장비·시간 쌍에서 추론한 연결 확률을 평균하여 공통 그래프 점수를 만들고, 검증·테스트 예측에서는 이를 고정하여 사용한다. **검증·테스트의 현재 정답을 인코더에 넣지 않는다.**

이 구조는 학습 가능한 인코더를 갖지만, 원논문의 전체 그래프 인코더를 그대로 옮긴 것은 아니다. 대상별 유입 연결을 출력하는 축소된 구성과 학습 구간 평균 그래프를 사용하는 절차를 포함한다.

연결의 사전확률은 0.1이며, 학습에서는 미분 가능한 연속 완화로 연결을 표본화한다. 평가에서는 이산 Bernoulli 연결을 64회 표본화하여 예측 분포를 계산한다. 따라서 학습 시의 연속 연결과 평가 시의 이산 연결 사이에는 차이가 있다.

### 4.4 직접 변분 모형

직접 변분 모형은 인코더 없이 전체 연결 확률의 파라미터를 직접 최적화한다. 디코더와 장비·유형별 기본 수준은 결정론적 모형과 동일한 구조를 사용한다. 그러나 연결을 고정 연속 가중치로 쓰는 대신, 연결 여부에 대한 Bernoulli 분포를 학습하며 평가 때 64개의 이산 그래프 표본을 사용한다.

즉, 세 신경망 모형의 차이는 다음과 같이 요약할 수 있다.

| 모형 | 연결 정보를 만드는 방식 | 예측 시 연결 처리 |
|---|---|---|
| TNPAR 참고 인코더 | 관측을 입력받는 인코더로 연결 확률 추론 | 학습 구간에서 집계한 확률로 그래프 표본 생성 |
| 직접 변분 | 공통 연결 확률의 파라미터를 직접 학습 | 학습한 확률로 그래프 표본 생성 |
| 결정론적 연결 | 공통 연속 연결 가중치를 직접 학습 | 학습한 연속 가중치를 그대로 사용 |

다만 TNPAR 참고 모형과 직접 변분 모형은 KL 규제의 정규화 단위도 다르다. 전자는 국소 유입 그래프의 KL을 관측 단위로 평균하고, 후자는 공통 그래프의 KL을 전체 학습 관측 수로 나눈다. 따라서 두 모형의 차이를 오직 인코더의 존재 여부만으로 설명할 수는 없다.

### 4.5 S²GCSL 참고 고정창 모형과 THP 참고 모형

S²GCSL 참고 모형은 최근 5개 구간의 위상 집계 발생 이력을 이용하고, 비음수 선형 영향 가중치와 장비·유형별 기본 수준을 학습한다. 신경망처럼 복잡한 비선형 상호작용을 만들기보다, 과거 발생량이 이후 발생량을 가산적으로 높이는 형태이다. 실제 사건 지속시간 대신 고정된 5구간의 영향 창을 가정한다.

THP 참고 모형은 과거 사건의 영향을 지수적으로 감쇠시키며 전체 과거 이력을 활용한다. 고정 부모 집합에 대해 EM으로 모수를 추정하고, BIC를 이용하여 간선 추가·삭제·반전을 탐색한다. 본 구현의 기본 발생 수준은 유형별로 장비 간 공유되므로, 다른 네 모형의 장비·유형별 기본 수준과 다르다.

이 차이들은 각 접근의 특성인 동시에 비교 해석의 제한이다. 다섯 모형은 같은 관측 자료와 물리적 위상을 사용하지만, 과거 이력의 범위·기본 수준의 표현·구조 선택 방식까지 완전히 같지는 않다.

## 5. 실험 방법

### 5.1 학습과 모형 선택

세 신경망 모형은 Adam으로 학습하며 학습률 0.0003과 0.001을 후보로 비교하였다. 연결 초기값 또는 사전확률은 0.1이다. 미니배치는 장비·시간 쌍 2,048개이고, 각 쌍에서 24개 유형을 평가한다. 최대 학습 길이는 3,000번의 파라미터 갱신이다. 이는 전체 자료를 3,000번 훑는 3,000 epoch를 의미하지 않는다.

검증은 100번 갱신마다 수행하며 최소 600번 갱신 후 조기 종료를 허용한다. 검증 성능이 8회 검사 동안 개선되지 않으면 종료한다. 기울기의 크기는 10으로 제한한다. 예측 손실 외에 희소성 규제와 약한 비순환성 규제를 사용한다. 결정론적 모형에는 Bernoulli posterior가 없으므로 KL 항은 없다. 규제 설정이 다르므로 결과를 규제 효과까지 통제한 완전한 절제 실험으로 보지는 않는다.

S²GCSL 참고 모형은 두 학습률과 두 규제 조합으로 총 네 후보를 비교하였다. THP 참고 모형은 고정한 감쇠율과 BIC 설정 아래 학습 구간에서 구조를 탐색하였다. 즉, THP의 선택 원리는 다른 네 모형의 검증 예측 손실 선택과 다르다.

검증에는 관측값과 연결 라벨을 보고 고르지 않은 최대 25,000개의 장비·시간 쌍을 사용하였다. 선택 점수는 평균 예측 발생량에 대한 포아송 점수이며, 모든 후보는 해당 반복의 테스트 평가 이전에 선택하였다. 테스트 결과로 학습률·구조·임계값을 바꾸지 않았다.

### 5.2 반복의 의미

TNPAR 참고 모형, 직접 변분 모형, 결정론적 모형, S²GCSL 참고 모형은 같은 데이터와 시간 분할에서 학습을 세 번 수행하였다. 각 반복에서 후보를 학습하고 검증을 통해 선택한다. 반복 간에는 초기화와 미니배치 등 학습 난수가 달라진다.

THP는 현재 구현에서 확률적 초기화를 사용하지 않는 EM·BIC 절차이므로 최초 결과 한 번을 재사용하였다. THP를 세 번 독립 학습했다고 표기하지 않는다. 표의 평균±표준편차는 나머지 네 모형의 학습 반복 세 번에 대한 값이다. **새로운 실제 데이터 세 개에서 얻은 평균이나 독립 데이터 반복의 신뢰구간이 아니다.**

실제 데이터에 한정하면 최초 11개 후보 학습·5개 선택 평가와 추가 20개 후보 학습·8개 선택 평가를 합쳐, 총 31개 후보 학습과 13개 선택 평가가 기록되어 있다.

### 5.3 예측 평가 지표

주지표는 관측된 발생 개수에 대한 예측 음의 로그우도, NLL이다.

\[
\operatorname{NLL}=-\frac1M\sum_{a=1}^{M}\log\widehat p(Y_a\mid\mathcal H_a).
\]

관측값에 높은 확률을 부여하면 NLL이 작아진다. 평균값이 실제 관측과 가까운지만 보는 것이 아니라, 관측 결과를 예측 분포가 얼마나 잘 설명하는지 평가한다.

TNPAR 참고 모형과 직접 변분 모형의 주지표는 그래프 표본 64개에서 얻은 포아송 분포를 섞은 예측 분포의 NLL이다.

\[
\widehat p(y)=\frac1{64}\sum_{s=1}^{64}\operatorname{Poisson}(y;m^{(s)}).
\]

이는 평균 발생량 \(\bar m\)을 먼저 구한 뒤 단일 포아송 분포로 계산한 NLL과 일반적으로 다르다. 검증 선택은 후자의 평균 발생량 점수를 사용한다. 이 차이를 감추지 않으며, 테스트에서는 두 점수를 구분하여 확인하였다. 결정론적 모형은 두 방식 모두에서 가장 낮은 NLL을 보였다.

보조 지표는 다음과 같다.

\[
\operatorname{MAE}=\frac1M\sum_a|Y_a-\widehat m_a|,
\qquad
\operatorname{RMSE}=\sqrt{\frac1M\sum_a(Y_a-\widehat m_a)^2}.
\]

MAE는 평균 절대 오차, RMSE는 큰 오차에 더 민감한 오차 지표이다. 확률 그래프 모형의 점 예측은 그래프 표본별 기대값의 평균을 사용한다. 세 지표 모두 작을수록 좋다.

### 5.4 기준선과 보조 분석

학습 구간에서만 계산한 장비·유형별 평균 발생량을 이후 모든 시점에 동일하게 적용하는 **시간불변 포아송 기준선**을 사용하였다. 이는 과거 변화나 이웃 장비의 상태를 이용하지 않고, 해당 장비·유형이 평소 얼마나 자주 발생했는지만 반영한다. 유형별로 장비를 합친 평균 기준선과 항상 0을 예측하는 점 예측 기준선도 확인하였다.

자료가 매우 희소하므로, 테스트에서 실제 발생 개수가 양수인 관측값에 한정한 보조 지표도 계산하였다. 이 분석은 예측 시점에 양수 관측을 미리 알아서 고르는 방법이 아니라, 예측 완료 후 오차를 살펴보는 **결과 조건부 기술 분석**이다. 주평가 대상을 양수 관측으로 바꾸거나 모형 선택에 사용하지 않았다.

### 5.5 결과 검증과 계산 환경

추가 실험은 Kaggle T4 GPU 두 개에서 수행되었다. 전체 추가 작업에는 실제 데이터 외 다른 기록도 포함되어 있으며, 전체 실행 시간은 약 36분 22초였다. 따라서 이를 실제 데이터만의 실행 시간이라고 표현하지 않는다. 해당 실행 시간에 GPU 두 개를 곱하면 약 1.21 장치·시간이지만, 준비 시간을 포함한 Kaggle의 공식 할당량 차감값을 직접 확인한 수치는 아니다.

회수한 결과에 대해 원본 자료와 소스 해시, 후보 선택 기록, 체크포인트의 유한값, 예측값으로 재계산한 NLL·MAE·RMSE, GPU 환경 기록을 확인하였다. 검토 결과는 독립 검증 완료 상태로 저장되어 있다. 이는 계산과 기록의 일관성을 확인한 것이며, 통계적 독립 검증 데이터가 추가되었다는 의미는 아니다.

반면 전체 MAE에서는 항상 0을 예측하는 기준선이 결정론적 모형보다 낮았다. 대부분의 관측값이 0이기 때문에, 적은 양의 발생량을 예측하는 것조차 많은 구간에서 절대 오차를 더할 수 있다. 따라서 “모든 예측 지표에서 모든 기준선보다 좋다”는 표현은 부정확하다.

항상 0인 점 예측에 포아송 평균 0을 그대로 부여하면 양수 관측의 확률은 0이 되어 NLL이 무한대가 된다. 따라서 표에서는 이를 유효한 양수 강도 포아송 기준선의 NLL로 제시하지 않았다. 이 비교는 **확률 예측과 희소 자료의 점 예측이 다른 목적을 가질 수 있음**을 보여준다.

### 6.5 연결 평가: 예측 성능과 다른 결과

제공 참고 그래프에는 자기 연결을 제외한 552개 가능한 유형 간 방향 연결 중 137개가 표시되어 있다. 아래 지표는 이 참고 라벨에 대한 일치도이다.

**표 5. 연결 점수 순위 및 각 모형의 기존 판정 규칙에 따른 F1**

| 모형 | AP: 평균±표준편차 | 기존 판정 규칙의 F1: 평균 |
|---|---:|---:|
| TNPAR 참고 인코더 | 0.278 ± 0.007 | 0.000 |
| 직접 변분 | 0.293 ± 0.007 | 0.000 |
| 결정론적 연결 | 0.300 ± 0.002 | 0.000 |
| S²GCSL 참고 고정창 | 0.335 ± 0.005 | 0.074 |
| THP 참고 모형 | 0.244 | 0.110 |

세 신경망 모형은 확률 또는 게이트에 0.5 임계값을 적용했을 때 간선이 선택되지 않아 Precision·Recall·F1이 모두 0이고 SHD는 137이었다. S²GCSL 참고 모형은 구간당 영향 가중치 0.001, THP는 BIC로 선택한 이진 그래프를 사용하였다. 판정 규칙과 점수 단위가 다르므로 위 F1을 동일한 임계값 조건의 순수한 우열로 읽어서는 안 된다. 특히 신경망의 0.5 판정이 원논문의 최종 그래프 판정 절차와 동일하다고 확인된 것은 아니다.

AP는 연결 점수를 높은 순서로 나열했을 때 참고 연결이 앞쪽에 오는지를 평가한다. 참고 연결의 비율은 약 0.248이므로 이를 단순한 순위 비교의 참고 수준으로 사용할 수 있지만, 유한 표본 무작위 AP의 정확한 기대값이나 통계적 유의성 기준은 아니다. 결정론적 모형의 AP 0.300은 일부 순위 정보를 시사하지만, 강한 연결 복원 성능이라고 보기 어렵다. S²GCSL 참고 모형은 AP가 가장 높지만 예측 NLL은 가장 좋지 않았다.

따라서 현재 결과로는 “결정론적 모형이 인과 구조를 가장 잘 찾는다”거나 “연결이 충분히 설명 가능하게 복원되었다”고 주장할 수 없다. 연결 임계값을 테스트 결과에 맞춰 조절하여 F1을 높이지 않았으며, 연결 지표는 본 연구의 주된 예측 결론과 분리한다.

## 7. 논의

### 7.1 현재 결과가 뒷받침하는 주장

가장 직접적인 결론은 **이 공개 통신망 데이터와 현재 비교 설정에서 결정론적 연결 모형의 발생 개수 예측 성능이 가장 좋았다**는 것이다. NLL뿐 아니라 다섯 모형 내 MAE·RMSE 순위와 발생 관측의 보조 지표도 이를 지지한다. 세 학습 반복에서 순위가 유지되었다는 점은 학습 난수에 대한 안정성을 보완한다.

결정론적 모형을 단순히 “평균값만 잘 맞춘 모형”이라고 제한할 필요는 없다. 현재 비교에서는 단일 포아송 예측 분포의 NLL이 그래프 혼합 예측 분포보다 낮았다. 다만 예측 구간의 포함률·폭 또는 다른 분포 적합성을 충분히 검증한 것은 아니므로, 확률적 불확실성 표현까지 전반적으로 더 우수하다고 결론내릴 수는 없다.

### 7.2 결정론적 모형이 유리했던 이유: 가능한 설명

결정론적 모형은 연결을 매번 이산 표본으로 바꾸지 않고, 학습한 연속 가중치를 그대로 입력에 적용한다. 따라서 약한 정보를 유지하면서 디코더와 함께 최적화할 수 있고, 학습 때와 예측 때의 연결 표현도 더 일관적이다. 관측이 매우 희소한 현재 환경에서는 이 방식이 안정적인 예측에 유리했을 가능성이 있다.

그러나 이는 **실험으로 확정한 원인이 아니라 가설**이다. 인코더 모형에는 추가 파라미터, 국소 추론과 시간 집계, KL 규제가 존재한다. 직접 변분 모형에는 그래프 표본 변동과 학습·평가 간 완화 차이가 존재한다. THP에는 다른 기본 수준과 이력 범위가 있고, S²GCSL에는 고정창 근사가 있다. 현재 비교만으로 어느 요소가 성능 차이를 만들었는지 하나로 확정할 수 없다.

특히 “인코더가 필요 없다”는 일반 명제를 주장하지 않는다. 데이터가 여러 계열로 구성되거나, 새 계열에서 연결 구조를 빠르게 추론하거나, 시간에 따라 구조가 달라지는 문제에서는 인코더의 역할이 달라질 수 있다. 본 연구는 그러한 환경을 평가하지 않았다.

### 7.3 예측과 설명 가능성

결정론적 게이트는 어떤 과거 유형의 정보를 얼마나 통과시키는지 보여준다는 점에서 관찰 가능한 내부 구조를 제공한다. 그러나 게이트와 디코더 가중치가 함께 작동하기 때문에, 게이트 크기를 곧바로 인과 효과 크기로 해석하면 안 된다.

현재처럼 0.5 임계값 F1이 0이더라도 연속 가중치와 디코더를 이용한 예측 학습은 진행될 수 있다. 반대로 예측이 좋다는 이유로 연결 학습도 성공했다고 결론내릴 수 없다. 논문에서는 **구조화된 입력 선택을 이용한 예측 모형**이라는 설명이 안전하며, 인과 구조 발견 또는 원인 진단의 정확성을 주된 기여로 내세우지 않는 편이 현재 증거에 부합한다.

## 8. 한계와 해석상의 주의

첫째, 실제 데이터는 단일 공개 통신망 자료이며 관측 기간도 약 6일이다. 다른 통신망·기간·집계 간격에 대한 일반화는 확인하지 않았다. 세 반복은 학습 난수 반복이지 독립 자료 반복이 아니다. 작은 반복 표준편차를 일반화 성능의 신뢰구간이나 유의성으로 해석하지 않는다.

둘째, 이 자료와 결과를 활용하여 개발과 검토를 진행했으므로, 완전히 새로운 자료에서 수행한 독립 확증 실험은 아니다. 각 반복 내 검증 선택과 테스트 평가는 분리했지만, 이 사실만으로 연구 과정 전체의 독립성이 확보되는 것은 아니다.

셋째, 원논문 모형은 공통 발생 이력 예측을 위해 수정된 참고 구현이다. TNPAR의 인코더·집계 방식, S²GCSL의 지속시간 처리, THP의 구간 우도 근사가 다르다. 따라서 원저자 알고리즘의 최고 성능을 꺾었다거나 원논문의 결과를 부정했다고 표현할 수 없다. 공개 자료 저장소에서 제시하는 기존 THP 연결 성능도 본 연구와 절차가 같지 않으므로 동일 재현의 목표값으로 취급하지 않는다.

넷째, KL 정규화·기본 수준·과거 이력·모형 선택 방식이 모두 동일하지 않다. 공통 입력 정보 아래의 구현 비교이지만, 모든 조건을 맞춘 순수한 인코더 제거 실험은 아니다.

다섯째, 결정론적 모형의 선택된 학습 시점은 세 반복 모두 최대 3,000 갱신 지점이었다. 일부 다른 모형도 최대 갱신 수에 도달하였다. 따라서 모든 모형이 충분히 수렴했다거나, 더 오래 학습해도 순위가 동일하다는 것은 확인하지 못했다.

여섯째, 매우 많은 0과 소수의 양수 관측이 공존한다. 전체 MAE는 0 예측에 유리하며, NLL과 RMSE는 다른 특성을 평가한다. 지표를 하나만 골라 전체적으로 우월하다고 표현하지 않는다. 연결 참고 라벨에 대한 AP·F1도 실제 세계의 인과 타당성 증명이 아니다.

## 9. 결론

본 연구는 공개 통신망 경보 자료에서 물리적 위상과 과거 발생 이력을 이용하여 다음 60초 구간의 경보 발생 개수를 예측하였다. 원논문을 참고하여 구현한 다섯 모형을 비교한 결과, 결정론적 연결 모형은 같은 데이터의 세 학습 반복에서 가장 낮은 예측 NLL·MAE·RMSE를 보였다. 평균 NLL은 TNPAR 참고 인코더보다 약 17.3%, 직접 변분보다 약 16.9%, 장비·유형별 시간불변 기준선보다 약 29.6% 낮았다.

다만 항상 0을 예측하는 기준선은 전체 MAE가 더 낮았으며, 결정론적 모형의 연결 복원이 성공했다고 볼 근거는 부족하였다. 따라서 본 연구의 결론은 **해당 공개 데이터와 구현 조건에서 연속 연결 가중치를 이용한 결정론적 모형이 유용한 발생 개수 예측 방법이었다**는 수준으로 제시한다.

포스터와 후속 논문은 ‘새 인과 발견 모형의 제안’보다 ‘위상 정보를 활용한 결정론적 모형의 통신망 경보 예측 적용 및 비교’로 구성하는 것이 현재 결과에 적합하다. 본 보고서의 초록은 상세 결과를 이해하기 위한 초안이며, 학회 제출용 분량과 형식에 맞춘 압축은 별도로 수행해야 한다.

| 용어 | 이 연구에서의 의미 |
|---|---|
| 위상·Topology | 장비끼리 물리적으로 어떻게 연결되어 있는지 나타내는 알려진 구조 |
| 경보 유형 간 연결 | 한 경보 유형의 과거 정보를 다른 유형의 예측에 전달하는 관계. 장비의 물리적 연결과 다른 대상 |
| MLP | 여러 층의 계산을 거쳐 입력과 출력 사이의 비선형 관계를 배우는 기본 신경망 |
| 인코더 | 관측 정보를 받아 어떤 연결이 존재할지에 대한 잠재 분포를 추론하는 신경망 |
| 디코더 | 연결과 과거 관측을 받아 이후 경보의 기대 발생량을 만드는 신경망 |
| 변분 추론 | 계산하기 어려운 잠재 연결의 분포를 다루기 쉬운 학습 가능한 분포로 근사하는 방법 |
| VAE형 구조 | 잠재 분포를 추론하는 인코더와 관측을 설명하는 디코더를 함께 학습하는 구성. 여기서 잠재 대상은 연결 구조 |
| Bernoulli 분포 | 연결 있음·없음처럼 두 가지 결과에 확률을 부여하는 분포 |
| KL 규제 | 학습한 연결 분포가 사전 연결 분포에서 얼마나 벗어나는지에 대한 제약. 너무 강하면 관측의 신호보다 사전확률을 따를 수 있음 |
| 연속 완화 | 0·1 연결의 표본을 학습 중에는 미분 가능한 연속값으로 근사하는 방법 |
| 결정론적 연결 게이트 | 무작위 연결 표본 없이 학습한 0~1 연속 가중치를 그대로 사용하는 입력 통과 장치 |
| Softplus | 실수 출력을 양수로 바꾸는 함수. 기대 발생량이 음수가 되지 않게 함 |
| NLL | 실제 관측 결과에 예측 분포가 부여한 확률을 평가하는 손실. 작을수록 관측을 잘 설명함 |
| 시간불변 기준선 | 학습 기간의 평균 발생량을 이후 모든 시간에 동일하게 예측하는 단순 모형 |
| AP | 높은 연결 점수부터 보았을 때 참고 연결이 앞에 오는지를 요약하는 순위 지표 |
| Precision·Recall·F1 | 선택한 연결의 맞은 비율, 참고 연결을 찾은 비율, 두 비율의 조화평균 |
| SHD | 추정 그래프와 참고 그래프의 구조 차이를 세는 지표. 본 평가에서 방향 반전은 1회 차이로 셈 |
| EM | 잠재 원인에 대한 기대값 계산과 모수 갱신을 번갈아 수행하는 추정 방법 |
| BIC | 적합도와 모형 복잡도를 함께 고려하여 구조를 선택하는 기준 |
| 학습 시드 반복 | 같은 데이터에서 학습 난수를 바꿔 다시 학습하는 것. 새로운 데이터를 수집하거나 생성하는 반복과 다름 |
